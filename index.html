New Alzaab Accounts

A Windows desktop app for companies to record and review their daily expenses. (Formerly called Employee Cost Tracker.)

Download

One zip with the Windows installer, the user manual (PDF) and a short read-me.

Download the latest version

Windows 10 or 11, 64-bit, administrator rights. The installer is not code-signed yet, so Windows may say "Windows protected your PC": click More info, then Run anyway. To upgrade, run the new installer over the old one; the data is kept.

What it does

  • An employee enters the day's expenses (cash, card, fuel, carpet, material and more, with a reason where needed) until the day's cut-off time.
  • Admins review, correct and export the expenses of their organisation.
  • The app can save a spreadsheet of each day, and of each month, to the company's own Google Drive.

Where the data lives

The app runs on a computer of the company that uses it. All data is stored there, encrypted. The developer does not run a server and does not receive any of the data.

Google Drive

When an admin connects Google Drive, the app asks only for the drive.file permission: it can see and change only the files it creates itself (a folder named "New Alzaab Accounts - <company>" with the day and month spreadsheets). It cannot read any other file in the Drive.
